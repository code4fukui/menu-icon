# menu-icon

ゼロ依存でカスタマイズ可能な、アニメーション付きメニューアイコン（ハンバーガーアイコン）のWebコンポーネントです。

## ライブデモ

実際のコンポーネントの動作は、以下のライブデモサイトで確認できます:
[https://fukuno.jig.jp/2833](https://fukuno.jig.jp/2833)

## 機能

- **ゼロ依存:** 軽量で独立したWebコンポーネントです。
- **複数のアニメーション:** 3種類の組み込みアニメーションスタイルが含まれています:
    - 3本線のアイコンが「X」に変化するアニメーション。
    - 4本線のアイコンが回転しながら「X」に変化するアニメーション。
    - 4本線のうち、外側の線がフェードアウトし、内側の線が「X」を形成するアニメーション（デフォルト）。
- **シンプルなトグル:** クリック時に `.change` クラスを切り替える（トグルする）ことでアニメーションします。

## 使い方

1.  **HTMLファイルにスクリプトを追加します。**

    ```html
    <script type="module" src="./menu-icon.js"></script>
    ```

2.  **HTML内でカスタム要素を使用します。**

    ```html
    <menu-icon></menu-icon>
    ```

これにより、ページの右下にデフォルトのメニューアイコンが表示されます。

## カスタマイズ

すべてのカスタマイズは `menu-icon.js` ファイルを直接編集することで行います。

### アニメーションスタイルの変更

コンポーネントには3種類のアニメーションスタイルが含まれており、それぞれインデックス `0`、`1`、`2` で指定します。デフォルトは `2` です。変更するには、コンストラクタ内の `changetype` のデフォルト値を変更します:

```javascript
// menu-icon.js 内
export class MenuIcon extends HTMLElement {
  constructor(changetype = 2) { // 別のスタイルにするには '2' を '0' または '1' に変更します
    super();
    // ...
  }
}
```

### 外観の変更（色、サイズ、位置）

- アイコンの**位置、背景色、余白（padding）**を変更するには、`menu-icon.js` の先頭にある `cssmenu` 定数を編集します。
- **線の色、サイズ、アニメーションのプロパティ**を変更するには、該当するスタイルの `barchanges` 配列内のCSSを編集します。
